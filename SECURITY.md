# Seguridad y datos locales

La emulación funciona sin conexión. El comprobador de actualizaciones consulta por HTTPS los metadatos públicos de bortisoftware/DigiBuddy en raw.githubusercontent.com, con la API de GitHub como respaldo si el archivo no existe, sin claves ni autenticación. Valida que la versión, la página y el adjunto correspondan al repositorio oficial. No transmite BIOS, juego, guardados, estadísticas ni identificadores del dispositivo; GitHub recibe la IP de la conexión como en cualquier acceso web. La consulta automática se puede desactivar en Ajustes y se realiza al abrir o volver a la app. Los archivos importados permanecen en el almacenamiento privado de Android; la tarjeta solo se exporta al destino elegido por el usuario. La copia de seguridad automática está desactivada.

El selector de archivos limita el tamaño importado y no confía en nombres del disco como rutas de escritura. Los lectores comprueban límites de memoria y archivos. La APK local/release desactiva la depuración y sus comandos de prueba; la APK debug es exclusivamente para desarrollo.

No publicar BIOS, imágenes de disco, estados, tarjetas, volcados de memoria, capturas de pruebas, claves de firma ni contraseñas. .gitignore y tools/check_publish.py ayudan a comprobar los archivos preparados. Ninguna revisión estática garantiza que un núcleo nativo no tenga vulnerabilidades; utilizar archivos propios y versiones verificadas.

Para un informe de error, compartir pasos de reproducción y versión de la app sin adjuntar BIOS, juego, claves ni datos privados. Los fallos funcionales pueden comunicarse en las Issues del repositorio; no publicar allí detalles de una vulnerabilidad explotable.

Las respuestas de actualización tienen límites de tiempo y tamaño. Los metadatos rechazan redirecciones, versiones malformadas y enlaces ajenos al repositorio oficial. La descarga de APK permite únicamente HTTPS y un máximo de cinco redirecciones entre GitHub y sus servidores de adjuntos. El archivo se guarda en la caché privada, con tamaño máximo de 64 MiB; antes de instalar se comprueban tamaño exacto, SHA-256 publicado, identificador de paquete, versión y coincidencia de certificados con la app instalada. El hash detecta alteraciones del archivo y la firma verifica su origen. Un proveedor no exportado concede lectura exclusivamente a la APK para el instalador; no permite escribir ni acceder a otros archivos. Android requiere permiso de instalación desde DigiBuddy y confirmación del usuario. La descarga se puede cancelar; cerrar la Activity interrumpe el trabajador y elimina archivos parciales.
